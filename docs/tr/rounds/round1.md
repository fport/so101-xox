# Tur 1 · 9 blok × 5 bölüm = 45 bölüm

[English](../../rounds/round1.md) · **Türkçe**

Üretildi: `python scripts/recording_plan.py --round 1 --episodes 5 --first 0 --seed 1 --lang tr`

Her kutu bir bölümün **başlangıç** tahtası. Bölüm başlamadan önce `X` ve `O` yazan hücrelere o taşı koy,
`*` hedef hücre: boş bırak, robot X'i oraya koyacak. Boş kutu boş hücre.

Kutular masaya kolun arkasından bakıyormuş gibi çizili:

```
          robottan uzak (top)
         ┌───┬───┬───┐
         │   │   │   │
 O'lar   ├───┼───┼───┤   X'ler
         │   │   │   │
         ├───┼───┼───┤
         │   │   │   │
         └───┴───┴───┘
             ROBOT
```

# Round 1 · 9 blocks × 5 episodes = 45 episodes

**English** · [Türkçe](../tr/rounds/round1.md)

Generated: `python scripts/recording_plan.py --round 1 --episodes 5 --first 0 --seed 1`

Each box is the **starting** board of one episode. Before the episode starts, put that piece in the cells marked `X` and `O`.
`*` is the target cell: leave it empty, the robot will put the X there. An empty box is an empty cell.

The boxes are drawn as if you were looking at the table from behind the arm:

```
          far from robot (top)
         ┌───┬───┬───┐
         │   │   │   │
 O's     ├───┼───┼───┤   X's
         │   │   │   │
         ├───┼───┼───┤
         │   │   │   │
         └───┴───┴───┘
             ROBOT
```
